# 进厂车辆信息登记 Web App

桂康工厂提货登记系统，基础功能包含：

- 用户身份验证
- 登录后登记提货车辆信息
- 粘贴文本自动识别并回填表单
- 支持用 `//` 分割多个车辆信息，自动生成多张车辆表单
- 可手动填写提货车辆表单
- 多个车辆默认共用同一个日期、公司抬头和合同号
- 每个用户仅能看到自己的提交记录
- 车辆表单数据使用本地 JSON 文件保存

## 字段

1. 提货日期
2. 提货公司
3. 合同号
4. 车牌号
5. 司机姓名
6. 司机身份证号
7. 司机电话号码
8. 货物品类（碳锰、硅锰、其它）
9. 提货吨位
10. 备注信息

## 本地试运行

在项目目录中执行：

```bash
node server.js
```

打开 `http://localhost:3000`。


## 默认管理员账号

- 用户名：`admin`
- 密码：`admin123`



## 说明

信息智能识别目前是本地规则解析，适合司机信息文本、合同信息、车牌和吨位的常见格式。
