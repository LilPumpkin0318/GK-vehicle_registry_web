# 进厂车辆信息登记 Web App

这是桂康工厂提货登记系统，包含：

- 登录后登记提货车辆信息
- 提货公司默认使用当前用户名
- 粘贴文本自动识别并回填表单
- 支持用 `//` 分割多个车辆信息，自动生成多张车辆表单
- 支持左侧手动新增提货车辆表单
- 如果识别不到日期，会默认使用当天
- 多个车辆默认共用同一个日期、公司抬头和合同号
- 每个用户仅能看到自己的提交记录
- 数据使用本地 JSON 文件持久化

## 字段

1. 提货日期
2. 提货公司
3. 合同号
4. 车牌号
5. 司机姓名
6. 司机身份证号
7. 司机电话号码
8. 货物品类（碳锰、硅锰、其它）
9. 提货吨位

## 运行

在项目目录中执行：

```bash
node server.js
```

打开 `http://localhost:3000`。

## 默认账号

- 用户名：`admin`
- 密码：`admin123`

首次使用时也可以直接输入新用户名和密码，系统会自动创建本地账户。

## 说明

信息智能识别目前是本地规则解析，适合司机信息文本、合同信息、车牌和吨位的常见格式。
