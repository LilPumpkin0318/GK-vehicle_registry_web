# 工厂提货车辆信息登记 Web App


这是一个基于 **Node.js +  HTML/CSS/JavaScript** 的面向工厂提货场景的 车辆信息录入系统，核心目标是减少人工重复填写、自动化信息传递，提高车辆信息登记效率。  
系统支持登录、批量识别、分车号拆分、历史记录查看，并且可以通过修改前端识别规则来适配不同的现场文本格式。

项目特点：
- 用户验证身份信息后才能进入系统
- 支持手工新增提货车辆表单
- 支持粘贴车辆信息后自动识别并拆分多个表单
- 支持 `//` 分割多个车辆信息
- 支持多车号一次性提交
- 支持同一批次共享一个提货日期、公司抬头和合同号
- 提供“备注”字段，允许客户提出特殊要求
- 右侧展示当前用户自己的提交记录

## 一、技术栈

- 后端：Node.js 原生 `http` 模块
- 前端：原生 HTML、CSS、JavaScript
- 数据存储：本地 JSON 文件
- 登录方式：本地用户名 + 密码 + Cookie 会话

## 二、功能说明

### 1. 登录与会话
- 首次登录时会自动创建本地用户
- 登录成功后会写入 Cookie
- 每个用户只能看到自己的提交记录

### 2. 提货登记
单条车辆记录包含以下字段：
- 提货日期
- 提货公司
- 合同号
- 车牌号
- 司机姓名
- 司机身份证号
- 司机电话号码
- 货物品类
- 提货吨位
- 备注

### 3. 批量识别
- 将车辆信息粘贴到上方文本框后，系统会自动尝试识别
- 多辆车信息可以用 `//` 分隔
- 如果未识别到提货日期，系统默认使用当天日期
- 如果一次提交多个车号，系统会把共享字段当作同一批次信息处理

### 4. 历史记录
- 右侧列表只做预览展示
- 当前只显示三项：`日期 · 合同号 · 车牌号`
- 实际保存时仍保留完整字段

## 三、项目结构

```text
factory-vehicle-registry-web/
├─ server.js
├─ package.json
├─ README.md
├─ public/
│  ├─ index.html
│  ├─ styles.css
```

### 文件职责

- [server.js](./server.js)：后端入口，负责登录、会话、记录保存、记录查询、字段校验
- [public/index.html](./public/index.html)：页面结构，定义登录页、登记页、表单模板、历史记录模板
- [public/styles.css](./public/styles.css)：页面样式与布局
- [public/main.js](./public/main.js)：当前生效的前端逻辑，负责自动识别、批量拆分、表单渲染、提交和记录展示
- [data/users.json](./data/users.json)：本地用户数据
- [data/sessions.json](./data/sessions.json)：本地登录会话数据
- [data/records.json](./data/records.json)：提交记录数据

## 四、运行方式（当前仅支持本地测试）

### 1. 启动项目

在项目目录下执行：

```bash
node server.js
```

也可以使用：

```bash
npm start
```

### 2. 打开网页

浏览器访问：

```text
http://localhost:3000
```

### 3. 默认账号

- 用户名：`admin`
- 密码：`admin123`

首次使用时，也可以直接输入新的用户名和密码登录，系统会自动创建本地账号。

## 五、页面使用说明

### 登录页
- 输入用户名和密码后登录
- 首次输入新的用户名和密码时，会自动建号

### 左侧登记区
- 上方文本框用于粘贴原始车辆信息
- 点击“智能拆分并填表”可自动识别
- 点击“新增提货车辆”可手动增加一张车辆表单
- “清空文本”只清空粘贴框和当前预览，不会删除已保存记录

### 车辆表单预览
- 每张卡片对应一辆车
- 可以手动修改识别结果
- “备注”字段允许留空

### 右侧历史记录
- 只显示当前用户的记录
- 支持按合同号或车牌号搜索

## 六、字段与匹配规则

这一部分是本项目重要的维护点。

### 1. 共享字段
共享字段是同一批车共用的内容：
- 提货日期
- 提货公司
- 合同号

对应逻辑主要在 `public/main.js` 里的：
- `parseSharedFields`
- `setCommonFields`
- `parseBatch`

### 2. 单车字段
每辆车自己的内容包括：
- 车牌号
- 司机姓名
- 司机身份证号
- 司机电话号码
- 货物品类
- 提货吨位
- 备注

对应逻辑主要在 `public/main.js` 里的：
- `parseVehicleFields`
- `collectVehicleRows`

### 3. 日期规则
- 如果文本里能识别到日期，就使用识别结果
- 如果没有日期，默认使用当天

对应函数：
- `findDate`

### 4. 车牌规则
- 支持从文本中提取一个或多个车牌号
- 如果同一段文本中出现多个车牌号，会自动拆成多个表单

对应函数：
- `extractPlateNumbers`
- `parseVehicleFields`
- `splitVehicleSegments`

### 5. `//` 批量拆分规则
- 如果文本包含 `//`
- 系统会把 `//` 两侧看成不同车辆信息段
- 每一段会生成一张车辆表单

对应函数：
- `splitVehicleSegments`
- `parseBatch`
